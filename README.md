# fabiobosio.com

Personal website for Fabio Bosio, an IT Developer Consultant.

## Tech used

- HTML
- CSS
- Vanilla JavaScript
- Google Fonts
- GitHub Actions
- GitHub Pages

## Live site

https://fabiobosioit.github.io/fabiobosio.com/

## Notes

- The site is bilingual: Italian in `it/`, English in `en/`; `index.html` picks the language.
- The site is static and has no build step.
- GitHub Pages deploys the repository root from the `main` branch.
