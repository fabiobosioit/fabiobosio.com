About me

Twenty-seven years of building software that people rely on every day.

I'm Fabio Bosio, an analyst and developer based in Lombardy, Italy. Since 1998 I've designed and built systems for banks, healthcare providers, software houses and non-profits — from mainframe procedures to modern web applications.

Who I am

From COBOL to cloud-ready web apps

I wrote my first lines of production code in November 1998, working on banking procedures in mainframe environments. Those years taught me rigour: when software moves money or tracks supervisory data, there is no room for guesswork.

Over time I moved into web and enterprise development — a Java MVC ERP for accounting firms, then .NET and Angular applications for patient admission, laboratory exams and dialysis treatments in healthcare. Today I build Drupal-based management systems for a non-profit in Milan, and I use AI-assisted coding tools like Cursor, Claude and GitHub Copilot to deliver faster without cutting corners.

What hasn't changed is how I work: I listen first, analyse carefully, and write software that the people using it can trust. I enjoy working in teams and keeping projects well organised and coordinated.
